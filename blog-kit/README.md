## 2. PC 스킨 꾸미기 (관리 → 꾸미기 설정 → 세부 디자인 설정)

1. **스킨 선택**: 흰 배경의 단순한 스킨(예: 기본 스킨 중 무늬 없는 것)을 고르세요.
2. **스킨배경** → 컬러 `#F6F3EE` (홈페이지 아이보리)
3. **타이틀** → 직접등록 → 이미지 등록
   - 사진형: `01_타이틀_사진형_966x400.png` → 영역 높이 **400**
   - 깔끔형: `01_타이틀_아이보리형_966x300.png` → 영역 높이 **300**
   - **"블로그 제목" 표시를 끄세요** (이미지 안에 이미 로고가 있어요)
4. **네이버 메뉴 / 블로그 메뉴** → 배경 `#1C1F26` 또는 `#00559F`, 글자 흰색
5. **포인트 색(글 제목, 카테고리 선택 등)** → `#00559F`
6. 적용 → **적용** 버튼으로 저장

## 3. 사이드 위젯 (관리 → 꾸미기 설정 → 레이아웃·위젯 설정 → 위젯 직접등록)

위젯 이미지는 홈페이지 주소에 올라가 있어야 보여요. `img/blog/` 폴더를 홈페이지에 **배포한 뒤** 아래 코드를 하나씩 붙여 넣으세요. (위젯 규격: 가로 170px, 세로 600px 이하)

**예약 위젯**
```html
<a href="https://map.naver.com/p/entry/place/1216957085" target="_blank"><img src="https://paranpilates.vercel.app/img/blog/widget-reserve.png" width="170" alt="네이버 예약"></a>
```

**홈페이지 위젯**
```html
<a href="https://paranpilates.vercel.app/" target="_blank"><img src="https://paranpilates.vercel.app/img/blog/widget-home.png" width="170" alt="홈페이지"></a>
```

**운영정보 위젯**
```html
<a href="https://map.naver.com/p/entry/place/1216957085" target="_blank"><img src="https://paranpilates.vercel.app/img/blog/widget-info.png" width="170" alt="운영시간 · 오시는 길"></a>
```

**전화 위젯**
```html
<a href="tel:01066944568"><img src="https://paranpilates.vercel.app/img/blog/widget-call.png" width="170" alt="전화 010.6694.4568"></a>
```

추천 순서: 프로필 → 예약 → 카테고리 → 운영정보 → 홈페이지 → 전화

## 6. 글 쓰는 틀 (스마트에디터)

```
[머리 이미지]  05_머리_○○.png
제목 아래 인사 2~3줄
[구분선]       07_구분선.png
본문 (사진 + 글)
[구분선]
[꼬리 이미지]  06_꼬리_스튜디오안내.png  → 이미지 선택 후 '링크'에 네이버 예약 주소 넣기
장소 첨부: 파란 필라테스 (네이버 지도)
```

- 한 번 만들어 두고 **템플릿 → 내 템플릿**으로 저장하면 매번 불러 쓸 수 있어요.
- 본문 글꼴: 나눔스퀘어 네오(홈페이지 글꼴과 가장 비슷), 강조 글자색 `#00559F`
- 인용구: "선" 스타일을 쓰면 홈페이지 느낌과 잘 맞아요.
- 대표 사진(썸네일): `08_썸네일_예시.png` 같은 형식. 새 글 제목을 알려주시면 같은 디자인으로 만들어 드려요.

## 이미지 다시 만들기

```bash
python blog-kit/build.py
python blog-kit/build.py thumb "거북목" "거북목, /*호흡*부터 바로잡아요" "Pilates Column" "photos/private-clean.jpg"
```
(`/`는 줄바꿈, `*단어*`는 하늘색 강조, 사진은 `img/` 폴더 기준 또는 정리된 사진 `photos/...`)

사진 정리(포스터·비상구 표시·CCTV 지우기, 천장 잘라내기)는 `python blog-kit/photos.py`로 다시 만들 수 있어요.
